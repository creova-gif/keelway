Three local surfaces

Studio, the governance server, and this website are different. Opening this page does not start a server.

Local Studio

core/studio on port 7420

From a clone, with dependencies installed, python3 cli.py dev serves the Studio UI from core.main:app. python3 cli.py desktop uses a Chrome or Chromium --app window when that browser exists, and otherwise opens a normal browser. make studio and make desktop call those commands.

$ python3 cli.py dev
Governance server

keelway-core serve on port 8000

make serve runs python3 -m keelway.cli.main serve --host 127.0.0.1 --port 8000. After an editable install the console script is keelway-core serve. The developer script keelway does not have a serve subcommand. The container entrypoint starts this process and does not include Studio.

$ make serve
Static site

website/ only

You are reading files from website/. vercel.json publishes that directory with empty install and build commands. The synthesizer on this page fills a file list in the browser. It does not call cli.py.

$ python3 cli.py build templates
Commands from a clone

Developer Quickstart & Early Access

Install from a clone of creova-gif/kora. The directory name is kora. These steps do not use a PyPI package named keelway, and they do not use a keelway.dev installer.

Developer Quickstart Git clone

Run from a clone

The editable install registers keelway (this is cli.py) and keelway-core (this is keelway.cli.main). Until that install exists, use the python3 commands below from the repository root.

terminal 
# Directory name is kora
$ git clone https://github.com/creova-gif/kora.git
$ cd kora
$ python3 -m venv .venv && source .venv/bin/activate
$ pip install -e ".[dev]"

# Local Studio (browser). Default 127.0.0.1:7420
$ python3 cli.py dev
# Browser-app window when Chrome or Chromium is installed
$ python3 cli.py desktop

# Governance server. Separate process on 127.0.0.1:8000
$ make serve

# List guided-builder templates. No model call.
$ python3 cli.py build templates
  • 1 Studio is python3 cli.py dev. It is the local IDE.
  • 2 The governance server is make serve / keelway-core serve.
  • 3 This page is static. It does not launch either process.
