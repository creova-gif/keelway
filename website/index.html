Local-first · deterministic · works offline

AI agents you can trust in production, on any connection.

Keelway is local-first, deterministic AI agent infrastructure for developers anywhere. Every run is an explicit state machine. Risky steps wait for a human. Everything is recorded so you can replay it. Local open-weight models are the default, so a typical loop costs $0.

Why agents break in production

Most agent frameworks assume fast, always-on internet and unlimited cloud credits. At $0.10 a loop, many teams can't afford them, and a dropped connection stops the work.

Opaque loops

A model calls tools in a loop until it decides it's done. When it goes wrong, nobody can say which step did what, or why.

Cloud cost on every step

Even simple steps go to a frontier model, so each loop costs money and needs an online connection.

Unchecked side effects

Agents write files and run commands with your credentials and nobody approves them. That's not something a security team can sign off on.

How a Keelway run works

A run is a state machine, not an open-ended loop. Each move to the next state is checked before it happens.

  1. Plan

    The goal becomes explicit steps that you can read in Studio before anything runs.

  2. Check

    The agent's manifest limits which tools and paths it may use. Anything outside that is refused.

  3. Approve

    Writes, commands and deploys pause for a human. Allow once, allow a narrow rule, or deny.

  4. Record

    Every step, model call and decision goes into a sealed flight tape you can inspect and replay later.

Local models first. Cloud only when it's worth it.

Keelway finds the model server already on your machine and uses a model you have installed. It routes to a cloud model only when a step needs one and you allow it.

Uses what you run

Detects Ollama, vLLM, llama.cpp server and LM Studio. It picks your configured model, then the one recommended for your RAM, then any installed chat model.

$0 per local loop

Local inference is billed at zero. Cloud models are chosen by cost, and the routing reason is shown for every request.

Air-gap mode

One switch blocks all outbound traffic: cloud models, messaging, telemetry. Private requests never leave the machine; if no local model is running, they fail instead.

An audit trail your security team can check

Every approval and permission decision is recorded in a form you can verify independently.

Hash-chained audit log

Each permission decision is linked to the one before, so any edit or deletion breaks the chain. Head anchoring publishes signed receipts to Git notes to prevent tail truncation.

Flight tapes

Append-only, sealed run records with secrets removed. Open one to see exactly what the agent saw and did, cryptographically bound into the audit chain.

Tier 2 Hardware Security

Dual-WORM storage receipts, TPM 2.0 measured boot and PCR quote replay, PIV smartcards with strict 72h CRL freshness, and 2-of-3 offline Shamir root recovery.

Manifest Registry & Cost Metering

Cryptographically signed manifests with instant kill switches, allowed tool/path fences, and per-run USD cost limits enforced fail-closed.

Tokens and roles

Every API route needs a token. Owner, admin, engineer and auditor roles. Only hashes of tokens are stored.

Scoped standing approvals

"Allow always" saves one narrow rule: one tool, in one workspace, for an exact command or a single path pattern. Each use is logged, and you can revoke it.

Protected paths

.git and Keelway's own state always ask for approval, so an agent can never approve itself.

Works with your editor

keelway mcp gives Cursor, Claude Code and Zed read-only workspace tools over MCP. Credentials files are hidden.

Approve from wherever you are

Studio is the main place to approve, but you don't have to be at your desk.

Studio

A task-first web app served by your own machine, with fonts and editor bundled so it works offline. Light and dark themes, right-to-left layouts, keyboard friendly.

Phone app

Pair your phone with your computer to see runs and approve with Face ID or a fingerprint. If the connection drops, it shows the last state you saw. In English, Kiswahili, French and Arabic.

Telegram and WhatsApp

Approve and Deny buttons arrive in chat. Each button works only for the action it was sent for. Turned off automatically in air-gap mode.

Quickstart

Keelway is in private preview. If you have access to the repository, this sets up a sample project and opens Studio on it. You need Python 3.11+ and git; Ollama is optional.

terminal
$ git clone https://github.com/creova-gif/kora.git keelway && cd keelway
$ python3 -m venv .venv && . .venv/bin/activate && pip install -e .
$ keelway demo   # sample project, tasks and a flight tape
# Optional, for $0 local runs: install Ollama, then  ollama pull qwen2.5-coder:7b
