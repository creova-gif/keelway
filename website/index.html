Three invariants

What Keelway guarantees on every run, whether you're pairing with it for an hour or leaving it on a task overnight.

1. Own Your Execution

Run on your own local models by default — zero per-token billing, zero egress unless you opt in.

2. Know What Changed

Review real diffs before anything merges. Every decision an agent made is on the record, not just the final patch.

3. Keep Your Work Portable

Define reusable autonomous agents using open declarative manifests (AgentSpec v1). Export complete source code and clean Git histories with zero platform lock-in.

Model freedom, your choice of boundary

Run fully local, bring your own cloud keys, go strictly air-gapped, or route through your own VPC runner. Same agent, same approval flow, whichever boundary you pick.

Local-first

Point it at a local model (Ollama and others) and nothing leaves your machine by default.

terminal
$ python3 cli.py models --help

Bring your own keys

Use Anthropic, OpenAI, or Gemini with your own API key when you want frontier models.

gateway config
$ python3 cli.py models --help

Air-gapped

keelway chat --air-gapped restricts the run to local models only, no cloud fallback.

terminal
$ python3 cli.py chat --help

Your own VPC runner

Run the agent inside infrastructure you control; it polls out, nothing has to reach in.

terminal
$ python3 -m keelway.cli.main runner --help

Three ways to run it

Studio for day-to-day use, a governance server for teams, and this site for docs and install.

Studio

The local IDE

A browser-based workspace on your machine, port 7420. Opens as a normal tab or, with Chrome installed, its own app window.

$ python3 cli.py dev
Governance server

For teams

A separate process, port 8000, that enforces approvals and keeps the audit record for everyone on a team.

$ make serve
This website

Docs and install only

Static — reading this page doesn't start, configure, or touch anything running on your machine.

$ python3 cli.py build templates

Developer Quickstart Git clone

Run from a clone

Clone it, install it editable, and run the commands below from the repo root.

terminal 
# Directory name is kora
$ git clone https://github.com/creova-gif/kora.git
$ cd kora
$ python3 -m venv .venv && source .venv/bin/activate
$ pip install -e ".[dev]"

# Local Studio (browser). Default 127.0.0.1:7420
$ python3 cli.py dev
# Browser-app window when Chrome or Chromium is installed
$ python3 cli.py desktop

# Governance server. Separate process on 127.0.0.1:8000
$ make serve

# List guided-builder templates. No model call.
$ python3 cli.py build templates
  • 1 Studio is python3 cli.py dev. It is the local IDE.
  • 2 The governance server is make serve / keelway-core serve.
  • 3 This page is static. It does not launch either process.
