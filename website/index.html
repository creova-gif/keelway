Features

Local-first

Local models by default. Cloud only when you choose it, and it keeps working offline.

Scoped approvals

"Allow always" per tool and path, never a blanket grant. Every rule is audited and revocable.

Verifiable record

A hash-chained log of every action. Anyone can verify it — no cloud account required.

See a real approval gate

A plan step, a human gate, an applied patch, a test run, a sealed record. (Illustrative example, not a captured session.)
