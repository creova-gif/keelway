Keelway interface identity

The public marketing pages use one mark, two color schemes, and the controls already on the site. This page is the reference for those parts.

Mark

The mark is the square in favicon.svg. The tile is #2DD4BF. The strokes stay #0B0F14. The header sets the same drawing at 30px beside the wordmark.

Color

Dark is the primary scheme in the interface specification. Light follows the system setting. Teal is the action and accent. Amber is a waiting decision. Red is a removed line or a fault. Names below are the tokens in styles.css.

Type

Interface and marketing text is Inter, then the system sans. Code and status chips are JetBrains Mono. Both are variable fonts served from this site, the same files the Studio ships, so pages render the same offline. Scripts outside Latin, Cyrillic, Greek and Vietnamese fall back to the system font.

Section title

Body text stays in a measure near seventy characters. Secondary sentences use the muted color at 16px, which is the size of the section introduction.

Controls

Buttons, links, and fields keep a 44px box. Keyboard focus is a 2px teal ring, 3px outside the control. Placeholder text uses the muted color.

Motion

Hover changes a border or a text color. Pressed buttons settle by a hundredth of their size. When the system asks for reduced motion, transitions, animations, and smooth scrolling turn off.

Use

Keep

The teal square and the #0B0F14 strokes. The wordmark “Keelway” with “by Sorvex Labs”. Dark and light from the tokens above. Code in a monospace face, inside a scroller when the line is wider than the column. Primary navigation visible at phone width, wrapped onto its own row.

Leave alone

A second logo, a renamed product, or a new color for the mark. Status and install sentences on the other pages. Hiding Features, Documentation, or API Reference below 820px. An 11px teal or amber label on a faint chip of the same hue.
