POST /v1/agent/builder/pack
Agent Builder

Pack an agent directory into a signed distributable .tar.gz bundle with SHA-256 digests and directory traversal protection.

Request JSON schema:
{ "source_dir": "agents/my-agent", "output_archive": "exports/my-agent.tar.gz" }
Response JSON:
{ "status": "packed", "archive_path": "exports/my-agent.tar.gz", "manifest": { "bundle_name": "...", "version": "1.0.0", "bundle_digest_sha256": "...", "files": {...} } }
POST /v1/agent/builder/unpack
Agent Builder

Unpack and cryptographically verify an agent bundle archive with anti-tamper checking.

Request JSON schema:
{ "archive_path": "exports/my-agent.tar.gz", "destination_dir": "agents/unpacked" }
Response JSON:
{ "status": "unpacked", "destination_dir": "agents/unpacked", "manifest": {...} }
POST /v1/khub/bundle/export
KHub Universal Skills

Export a skill directory or SKILL.md into a verified .skill.tar.gz bundle with SHA-256 member hashing.

Request JSON schema:
{ "skill_path": ".agents/skills/review", "output_archive": "exports/review.skill.tar.gz" }
Response JSON:
{ "status": "exported", "archive_path": "exports/review.skill.tar.gz", "manifest": { "skill_name": "review", "version": "1.0.0", "bundle_digest_sha256": "...", "files": {...} } }
POST /v1/khub/bundle/import
KHub Universal Skills

Import and cryptographically verify a portable .skill.tar.gz bundle into workspace skills with anti-tamper checking.

Request JSON schema:
{ "archive_path": "exports/review.skill.tar.gz", "destination_dir": ".agents/skills/imported_review" }
Response JSON:
{ "status": "imported", "destination_dir": ".agents/skills/imported_review", "manifest": {...} }
POST /v1/kspaces/{space_id}/conflicts/check
KSpaces Multi-Tenant

Perform 3-way AST merge conflict analysis between base, left, and right branch contents.

Request JSON schema:
{ "base_text": "...", "left_text": "...", "right_text": "...", "file_path": "service.py" }
Response JSON:
{ "has_conflicts": false, "auto_resolvable": true, "summary": "...", "hunks": [...] }
POST /v1/kspaces/{space_id}/conflicts/resolve
KSpaces Multi-Tenant

Synthesize resolved file content using automated AST strategy or specific branch priority.

Request JSON schema:
{ "base_text": "...", "left_text": "...", "right_text": "...", "strategy": "auto" }
Response JSON:
{ "status": "resolved", "resolved_text": "..." }
