POST /v1/agent/builder/pack
Agent Builder

Pack an agent directory into a signed distributable .tar.gz bundle with SHA-256 digests and directory traversal protection.

Request JSON schema:
{ "source_dir": "agents/my-agent", "output_archive": "exports/my-agent.tar.gz" }
Response JSON:
{ "status": "packed", "archive_path": "exports/my-agent.tar.gz", "manifest": { "bundle_name": "...", "version": "1.0.0", "bundle_digest_sha256": "...", "files": {...} } }
POST /v1/agent/builder/unpack
Agent Builder

Unpack and cryptographically verify an agent bundle archive with anti-tamper checking.

Request JSON schema:
{ "archive_path": "exports/my-agent.tar.gz", "destination_dir": "agents/unpacked" }
Response JSON:
{ "status": "unpacked", "destination_dir": "agents/unpacked", "manifest": {...} }
