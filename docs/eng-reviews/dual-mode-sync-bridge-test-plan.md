## Affected Pages/Routes
- `POST /v1/sync/open-in-editor` — Launches external editor (VS Code / Cursor) for current workspace worktree with path validation.
- `GET /v1/sync/status` — Returns watcher health, debounce queue state, and detected external editors.
- `POST /v1/sync/resolve-conflict` — Accepts developer resolution for concurrent edits (keep agent proposal or keep external edit).
- `core/studio/index.html` — Workspace top navigation bar "Open in VS Code / Cursor" button and active sync pill.

## Key Interactions to Verify
- Clicking "Open in VS Code" launches `code -r <worktree_path>` without disrupting running background agents.
- Saving a file in VS Code triggers immediate (150ms debounced) reload in Keelway Studio's Monaco editor if not currently modified by an agent.
- Modifying a file currently leased by an active agent pauses the agent, logs an auditable tape event, and opens the 3-way conflict modal in Studio.

## Edge Cases
- Rapid keystrokes / autosave bursts (10 saves in 100ms) are debounced into a single notification.
- Path traversal attack in `open-in-editor` payload (`../../../etc/shadow`) is strictly blocked.
- Editor CLI (`code` or `cursor`) not installed on user's machine returns clean HTTP 422 with instructions, not unhandled 500 error.
